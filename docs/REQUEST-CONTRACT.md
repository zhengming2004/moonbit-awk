# 0.10.1 嵌入请求与执行预算

AWK 核心的用途是将既有记录/字段语法嵌入 MoonBit 应用，由 Session 分步消费记录，或由宿主提供受控的输入/输出能力。AWK 语言、GoAWK、GNU awk都不是本项目首创；普通筛选未必需要AWK，只有需要该语义时才有采用理由。

这次审查修复了可复现的错误：`stepLimit:1.5`曾被截为1，null/错误类型曾回退到大默认值；小数session ID曾被截为另一个有效ID，甚至关闭那个会话。错误的参数/环境值也曾静默变为空字符串或被丢弃。现在这些请求显式失败。

- `stepLimit`省略才采用100000000；传入值必须是1..1000000000精确整数。Infinity/NaN不是合法JSON数字，其他非有限解析结果同样不能通过范围检查。
- `session`必须是1..Int32最大值精确整数。拒绝小数/回绕值发生在查找或移除会话之前，不影响另一个有效会话；内部ID耗尽时拒绝新建，不循环复用。
- `program`/action及动作必需的字符串不可省略或换类型；可选字符串省略保留原默认值，显式错误类型不回退。arguments必须全是字符串，variables/environment必须是字符串映射。
- 参数读取index也必须是非负精确整数。已经定位到有效会话后发生执行/动作错误，会按原契约关闭该会话，保留已产生输出；这不提供事务回滚。
- 宿主callback必须返回协议字符串；异常或错误类型变为IO失败。状态码必须是精确Int32，不能把1.5截为成功/另一状态。

`tools/test-request-contract.mjs`直接调用编译的MoonBit桥接，验证非法新建在任何宿主IO前失败、错误ID不影响活会话、真实无限循环被合法小预算终止、坏宿主回复不会截断为有效状态。原分步会话、CLI和pull-host回归分别验证批次输出、getline/流背压等真正消费路径。

步数预算是解释器工作量限制，不是墙钟/内存沙箱。宿主提供system、文件或管道能力时仍可执行命令或阻塞；要执行不可信脚本，调用方须决定能力暴露和独立进程隔离，不能把本库称为安全沙箱。库不自动获得用户文件/网络能力。

参考语义基线是实际安装并核对的GoAWK **v1.32.0**；历史差分记录覆盖声明的语义子集，本次只改请求契约，没有把历史全量golden说成本次重跑。没有企业存量脚本或客户采用证明。交付状态与当前检查见evidence/request-20260927，公开推送/发布由团队处理。
