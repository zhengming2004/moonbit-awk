# Validation contract

- Explicit Wasm-GC and JS targets: no inference from the toolchain default.
- Public API tests plus compiled browser engine, CLI stdin/file/argument and failure exit-code checks.
- 307 seeded bounded malformed inputs including UTF-16 surrogates. The worker has a 20-second limit.
- Local code coverage: `moon coverage analyze -p localreview/awk -- -f summary`. No coverage upload is configured. Coverage is evidence about current code, not upstream feature coverage.
- Benchmark: 5 warmups and 30 measured documented-example executions; median and p95 recorded locally.
- Generated API and browser artifact must match the same source revision.

CI files are prepared locally; remote CI has not run because this repository has not been uploaded. Compatibility beyond README scope remains unverified.

## 0.3 actual evidence

- JS and Wasm-GC: 15 tests each, including loops/control transfer, array aggregation/index side effects, numeric-string attributes, short-circuit evaluation, field reconstruction, builtins, ranges and budgets.
- `node tools/test-awk-cli.mjs`: 6 scenarios cover stdin, script/data files, separators, exit status, runtime errors and missing/unsupported inputs. Original `test-cli.mjs` also passed.
- `evidence/gawk-reference.json` was generated by installed GNU Awk 5.3.2 under WSL with LC_ALL=C.UTF-8, using `python3 tools/reference-gawk.py`. MoonBit is not invoked by the reference generator. Input definitions are in `tools/gawk-cases.json`; the source generator is retained.
- `node tools/test-gawk.mjs` compares against those independent results and records both engine/reference SHA-256 values. 44/46 cases match, with two retained differences: default numeric formatting and compile-time diagnosis of dead constant division. Array-iteration outputs alone are compared without ordering.
- Rerunning the comparison consumes the saved reference fixture; to refresh the reference itself, install GNU Awk and run the Python generator. This evidence is a representative corpus, not full POSIX/GoAWK conformance.
- No full workspace checks, new fuzz/coverage/performance run, archive rebuild, remote CI, upload or publication was performed in this stage. Earlier evidence keeps its original scope and date.
