# Validation contract

`verify.ps1` runs moon fmt/info/check, explicit JS and Wasm-GC tests, the example, a rebuilt browser engine, browser/legacy CLI/AWK CLI/session-bridge checks, saved GoAWK core and host vectors, historical GNU Awk vectors, bounded robustness and the documented-example benchmark. Generated API and engine must correspond to the checked source.

## 0.4 current evidence

- 25 public API test groups per JS and Wasm-GC target: expressions/control flow, arrays/fields, regex matching and substitution, Unicode positions, formatting and rounding, functions and scope, nonlocal transfer, sessions/independent state, step limits, numeric coercion/NaN/hexadecimal rounding and errors.
- `tools/test-reference.mjs`: 514 independently authored cases from an unmodified official GoAWK v1.32.0 executable with `-c -N raw`. Checks exact output and exit status, except unordered array iteration is sorted; designated invalid programs compare rejection, not identical diagnostics or partial output.
- `tools/test-host-reference.mjs`: 37 real CLI cases with multiple files/program files, -F/-v and positional assignments, ENVIRON/ARGV, nextfile/exit, CRLF/Unicode, failures and output before failures, and 4.8 MB input/output. Large output compares length and SHA-256. Live runs compare native process exit statuses; cross-platform golden replay compares low eight bits, while same-platform replay also compares the native status. Fixture files are created independently in an owned temporary directory.
- `tools/test-session.mjs`: verifies soft output batch boundaries, actual processed counts, output before batch/BEGIN failures, nextfile/exit, session cleanup and maximum simultaneous sessions. `test-awk-cli.mjs` keeps six basic CLI scenarios; original browser/combined-input CLI tests remain active.
- Live reports `evidence/awk-reference-validation.json` and `awk-host-validation.json` record executable version/SHA-256, engine, CLI and source hashes. Independent requests/reference outputs are in the corresponding vectors files. `--golden` strictly checks that saved request definitions still match; replay results use separate ignored files and do not overwrite live evidence.
- Reference: official [GoAWK v1.32.0 Windows asset](https://github.com/benhoyt/goawk/releases/tag/v1.32.0). The downloaded ZIP was checked against GitHub's asset digest (SHA-256 `2cebd8d64a8eaf84b2787edec8c0274760166e077bc2bdbb69d41537b56cf32c`). The external reference binary is used only by the test harness; it is not shipped or invoked by production code.
- Historical GNU Awk 5.3.2 vectors now match 45/46 cases: default numeric formatting is fixed; its compile-time rejection of dead constant division differs from GoAWK and this interpreter. The generator `tools/reference-gawk.py` is retained. This run replays that older corpus; it does not claim a fresh GNU reference generation.
- 307 seeded bounded malformed inputs, with a 20-second worker deadline; no uncaught runtime failures. This is bounded fuzz smoke coverage, not complete robustness proof.
- Benchmark: five warmups and 30 documented-example executions, runtime/CPU/median/p95 recorded locally. It is not an upstream performance comparison.

The 551 GoAWK comparisons are authored representative cases, not the entire upstream suite or a proof of POSIX/GoAWK conformance. Numeric/regex resource bounds, unsupported I/O/RS/CSV and Unicode/byte/locale gaps are documented in README. Native MoonBit backend, full upstream performance and remote CI remain unverified. All work is local; no coverage upload, archive refresh, publication or remote execution was performed.
